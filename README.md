# E-Voting-System-for-Disabled-Person
Final Year Project, which is based on E-Voting System for Blind and Visually Impaired people in pakistan.
This Project is a solution to a very big problem in Pakistan, In Pakistan Many people are unable to cast vote, because of their disability, such as blind, deaf, or unable to visit the voting system for some other reason.
It solves that issue for the Blind People by letting them to cast vote.
It achieves it using tools such as: WCAG rules, Text-to-Speech or also known as Screen Reader, Speech-to-Text, NLP, LLM and a chatbot.

**Text-to-Speech/Screen Reader:**
for reading the screen for the blind so that the blind could understand the layout of the screen and understand what he/she has to do.

**Speech-to-Text:**
for letting the user say the choices he wants to make for navigation, vote-casting and login.

**NLP:**
for correctly figuring out the words and sentences even in a noise.

**LLM:**
for Training the Model so that it can figure out the words that the voter is saying and map it to the segments on the screen.

**ChatBot:**
for guidance and help.
