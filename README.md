# E-Voting-System-for-Disabled-Person
Final Year Project, which is based on E-Voting System for disabled persons in pakistan.
This Project is a solution to a very big problem in Pakistan, In Pakistan Many people are unable to cast vote, because of their disability, such as blind, deaf, or unable to visit the voting system for some other reason.
It solves that issue by letting those disbaled person to cast their vote, by providing this portal to disabled persons specifically, and letting them cast their vote digitally.
